> the popup is new in 1.4.6 is **unverified** — see *存疑* in
> `deliverable.md`.

> **tmux downsamples.** `capture-pane -e` re-emits every SGR at cell

> colours agree. The clone renders truecolor (`\x1b[38;2;…`), the
> reference emits 256-colour (`\x1b[38;5;…`) — the same colours, two
> encodings. Every line below is copied verbatim out of a `capture-pane -e`

* the **marker + label** field is padded to **30 columns**; the catalogue

  three leading spaces). The reference has six models → `↓ 1 more`; the
  clone's catalogue also holds the two configured MiniMax models → `↓ 3
  more`. The **difference is the catalogue, not the layout**.

## 3. The filter is a substring of the label *or* of the id 【一手】

| query | reference's rows | note |
|---|---|---|
| `claude` | Claude Sonnet 4.6 (Thinking), Claude Opus 4.6 (Thinking) | label substring |
| `son` | Claude Sonnet 4.6 (Thinking) | **not** a subsequence — "Opus" has no `son` |
| `4.6` | both Claude rows | label substring |
| `onnet` | Claude Sonnet 4.6 (Thinking) | label substring |
| `sonnet-4-6` | Claude Sonnet 4.6 (Thinking) | **id** substring |
| `cl-opus` | — | a subsequence of the id, not a substring: nothing matches |
| `oss` | GPT-OSS 120B (Medium) | label substring |
| `120` | GPT-OSS 120B (Medium) | label substring |
| `zzz` | `   No matches` | the popup stays open |

This is **not** the `/model` *panel*'s matcher (a case-insensitive
**subsequence** of the display label — `docs/cycles/model-picker-search/`).
The completion popup is a plain substring match, and it looks at the
catalogue id as well.

## 4. Tab, Enter and the error 【一手】

```
reference, "/model claude" + Tab           reference, "/model Claude Sonnet 4.6 (Thinking)" + Enter
  ^[[38;5;32m>^[[39m ^[[38;5;32m/model^[[39m Claude Sonnet 4.6 (Thinking)     ^[[1m^[[38;5;32m> /model^[[0m
  ──────────────────────────────────────────────────────────────               ^[[1m^[[38;5;32m  ⎿  ^[[0m^[[38;5;60mModel set to Claude Sonnet 4.6 (Thinking)^[[39m
  ^[[39m                       auto · Claude Sonnet 4.6 (Thinking)              ──────────────────────────────────────────────────────────────
                                                                        (the popup is gone)

reference, "/model zzz" + Enter
  ^[[1m^[[38;5;32m> /model^[[0m
  ^[[1m^[[38;5;32m  ⎿  ^[[0m^[[38;5;60mInvalid model "zzz" (available: gemini-3.8-flash-high, gemini-3.8-flash-medium, gemini-3.8-flash-low,^[[39m
       ^[[38;5;60mclaude-sonnet-4-6, claude-opus-4-6-thinking, gpt-oss-120b-medium)^[[39m
```

* **Tab** completes the *highlighted row's label* into the composer
  (`/model Claude Sonnet 4.6 (Thinking)`) and closes the popup. It does
  **not** run the command.
* **Enter** runs the command when the argument names a model — exactly
  (case-insensitively) by label or by id. Then the transcript shows
  `> /model` + `  ⎿  Model set to <label>` (or `Model already set to
  <label>` when nothing changed).
* **Enter** with an argument that names no model but *matches* rows
  completes the highlighted row into the composer instead of running
  anything.
* **Enter** with an argument nothing matches runs the command and reports
  `Invalid model "<arg>" (available: <ids>)`. The reference **word**-wraps
  that line and indents the continuation by the width of the `  ⎿  `
  block prefix (5 columns).
* The reference's `available:` list holds the **six reference ids**. The
  clone's holds its own catalogue, so the two configured MiniMax models
  are listed too.

## 5. The status row drops `esc to cancel` in the model popup 【一手】

The reference's **command** popup puts `esc to cancel` at the left of the
status row; its **model** popup leaves that segment empty:

```
reference, "/mod" (command popup)          reference, "/model claude" (model popup)
  ↑/↓ Navigate · enter Select · tab Complete     ↑/↓ Navigate · enter Select · tab Complete
esc to cancel                    auto · Claude Opus 4.6 (Thinking)                                            auto · Gemini 3.8 Flash · high
```

The clone now does the same: `statusLeftSegment` returns an empty left
segment when the picker is in the model mode.

## 6. The command token is blue only when it is exact 【一手】

```
"/model"      → ^[[38;5;32m/model^[[39m          (blue — an exact command name)
"/quit"       → ^[[38;5;32m/quit^[[39m           (blue)
"/codesear"   → /codesear                        (plain — a prefix, not a name)
"/clea"       → /clea                            (plain)
"/mod"        → /mod                             (plain)
```

The reference's blue is the same blue as the prompt (`38;5;32`, the
clone's `#268BD2`).

## 7. Esc closes the popup, the hint stays 【一手】

```
reference, "/model " + Esc
  ^[[38;5;32m>^[[39m ^[[38;5;32m/model^[[39m ^[[38;5;66m[model]^[[39m
  ────────────────────────────────────────────────────────────────────────────
```

The composer keeps `> /model [model]`; the popup is gone. The clone's
capture is byte-identical to this line.

## 8. The print mode rejects the argument 【一手】

The reference's **print** mode does not complete anything — it validates:

```
$ agy -p "/model gemini-3.8-flash-medium"
error: /model takes no arguments, got "gemini-3.8-flash-medium"

$ agy -p "/effort high"
error: /effort takes no arguments, got "high"

$ agy -p "/help x"
error: /help takes no arguments, got "x"
```

Every locally-handled print-mode command rejects an argument this way.
The clone's print mode (`internal/printmode`, a different package from the
TUI) does not: `wagyu -p "/model x"` prints the model list and
`wagyu -p "/effort high"` sets the effort. That divergence is **pre-existing**
and is not touched by this cycle — see *limitations*.
