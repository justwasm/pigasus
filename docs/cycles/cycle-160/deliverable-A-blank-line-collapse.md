## Symptom

The captured 200×60 frames after cycle 159 still showed a one-row
blank-line drift:

```\n=== ref ===                            === ours ===\n    ?? rea-go-seeds/...                       ?? rea-go-seeds/...\n    ?? rea-go-seeds/analyzeAgyV135Tui.       ?? rea-go-seeds/analyzeAgyV135Tui.\n                                              [empty — was stripped fence opener]\n                                              [empty — was stripped fence closer]\n                                              [empty — was model-text blank line]\n  ## 为什么没污染历史                          ## 为什么没污染历史\n```

The cycle-158 fix changed `renderMarkdown` to replace the fence
marker line with `lines[i] = ""` (an empty placeholder). That kept
the line in the output stream — so a code block with surrounding
blank lines (very common: ref's model messages wrap code in
`` ``` `` + blank + content + blank + `` ``` ``) ended up with three
blank rows in a row. Ref collapses those to one blank.
